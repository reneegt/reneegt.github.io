# Susan Renee Giron Tena — Portfolio

Portfolio website built with HTML, CSS and JavaScript.

## Structure

- `index.html` — main page
- `style.css` — design and responsive layout
- `script.js` — navigation, scroll reveal and cursor effect
- `documents/CV-Susan-Renee-Giron.pdf` — add your CV here before publishing
- `assets/` — add your professional photo/project images here

## Publish with GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload all files from this folder.
3. Put your CV PDF in `documents/CV-Susan-Renee-Giron.pdf`.
4. In GitHub, open Settings → Pages.
5. Select the main branch as the publishing source.
6. Your site will be available at `https://yourusername.github.io/`.
